# VYRON Official Invite

Responsive purple/black landing page for VYRON#1678. The profile image is stored at `assets/vyron-avatar.jpg`.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then press **Save**.
4. Wait for GitHub Pages to finish publishing.
